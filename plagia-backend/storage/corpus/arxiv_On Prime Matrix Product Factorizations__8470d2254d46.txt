Abstract
A graph G factors into graphs H and K via a matrix product if A = BC, where A, B, and C
are the adjacency matrices of G, H, and K, respectively. The graph G is prime if, in every such
factorization, one of the factors is a perfect matching that is, it corresponds to a permutation matrix.
We characterize all prime graphs, then using this result we classify all factorable forests, answering
a question of Akbari et al. [Linear Algebra and its Applications (2025)]. We prove that every torus
is factorable, and we characterize all possible factorizations of grids, addressing two questions posed
by Maghsoudi et al. [Journal of Algebraic Combinatorics (2025)].

Prime Graphs
We start with the following simple lemma without proof.
Lemma 3.1. Let H be a perfect matching with the adjacency matrix B. Then B2 = I.
Any adjacency matrix of a perfect matching is a permutation matrix, which means that in
every row and every column there is exactly one 1. In addition, every n × n permutation
matrix corresponds to a permutation on Sn, which is a product of disjoint transpositions.
Each transposition corresponds to an edge of the matching. Thus, we have the following
corollary:
Corollary 3.2. Let H be a perfect matching with the adjacency matrix B. Then B can
be considered as an automorphism of H.
Let G, H, and K be graphs with the adjacency matrices A, B, and C respectively, such
that A = BC and B2 = I.
Since V (H) = V (G), then B can be considered as a map from V (G) to V (G). We next
show that B also can be regarded as an automorphism of G. But we need the following
lemma.
4

Lemma 3.3. Let H be a perfect matching with the adjacency matrix B. If G is a graph
with the adjacency matrix A, then BAB represents a relabeling of G.
Proof. By Lemma 3.1, B2 = I, so B = B−1. Since H is a perfect matching, B is a
permutation matrix. Thus BAB = BAB−1 = BABT, which means that BAB relabels
G by swapping each vertex with its matched partner in H.
Every automorphism of a graph G can be regarded as a permutation matrix. Keeping
this fact in mind, we prove the following theorem.
Theorem 3.4. Let G be a graph and H be a perfect matching with the adjacency matrix
B. Then G is factored into H and some K if and only if B is an automorphism of G
without any fixed edge.
Proof. Let A and C be the adjacency matrices of graphs G and K so that A = BC = CB.
Since B2 = I, BA = AB = C. Thus B is an automorphism of G. For the sake of
contradiction, suppose B fixes some edge {u, v} of G (so Bu = v and Bv = u). Then
{u, v} is an edge of both G and H, contradicting Lemma 2.4 (which states that G and H
have no edge in common).
Conversely, assume B is an automorphism of G with no fixed edge. Then BA = AB.
Because B and A are symmetric matrices, BA is also symmetric. Moreover, since B fixes
no edge of G, every diagonal entry of BA is 0 (no edge of G appears in both G and H).
Thus BA is a symmetric {0, 1}-matrix with zero diagonal, which we take as the adjacency
matrix of a graph K. By construction A = B(BA) = BC, so indeed G is factored into
H and K.

Definition 3.10. A subset U of V (G) = V (H ⊕K) is called alone if every vertex u′ of
V (G) ∖U has no neighbors in U in H ⊕K and G, i.e. NG(u′) ∩U = NH⊕K(u′) ∩U = ∅.
Lemma 3.11. Let a graph G be factored into H and K with a matched pair (u, v). Then
CK(u) ∪CK(v) is alone.
Proof. According to the diamond condition, every edge of G corresponds to an alternating
path in H ⊕K. This implies that every component of G is a subset of a component of
H ⊕K. Therefore, it is sufficient to show that CK(u) ∪CK(v) is alone in H ⊕K. Let
x ∈V (G)∖V (CK(u)∪CK(v)). We need to show that NH⊕K(x)∩(CK(u)∪CK(v)) = ∅. By
Corollary 3.9, we know that NH(CK(u)) = CK(v) and NH(CK(v)) = CK(u). Therefore, x
cannot be adjacent to any vertex in CK(u)∪CK(v) in H. Furthermore, CK(u) and CK(v)
are components of K, and thus there is no edge in K between x and CK(u) ∪CK(v).
Definition 3.12. Let G be a graph. Then G is prime if, for every factorization of G, one
of the factors is a perfect matching.
By definition, A graph without any factorization is prime.
Remark 3.13. If a prime graph G is factorable, then G has an even number of vertices.
We now are ready to prove the main theorem of this section.
Theorem 1.2. The graph G is prime if and only if every factorization contains a matched
pair endpoint in each component of G.
Proof. If G factors into H and K with H a perfect matching, then trivially the endpoints
of each H-edge form a matched pair (as desired).
For the backward implication, assume that G factors into H and K. Consider any vertex
x in H, and let C be the component of G containing x. By assumption, there is a matched
pair u, v such that u ∈C. By Lemma 3.11, CK(u) ∪CK(v) is alone, which implies that
x ∈CK(u) ∪CK(v). By Lemma 2.5, degH(z) = 1 for every z ∈CK(u) ∪CK(v), it follows
that degH(x) = 1, which implies that H is a perfect matching.

Lemma 4.1. [1, Lemma 19] Let a graph G be factored into two graphs H and K. If G
has no C4, then for every vertex u ∈V (G), either degK(u) = 1 or degH(u) = 1.
Lemma 4.2. Every graph with no C4 is prime.

Proof. Let C be a component of H ⊕K. If C is 2-regular, then for each vertex u ∈V (C)
we have degH(u) = degK(u) = 1, so each H-edge in C is a matched pair. If C is not

again, we find degH(NH(u)) = 1, so {u, NH(u)} is a matched pair.
Since C was an
arbitrary component of H ⊕K, Theorem 1.2 ensures that G is prime.
Lemma 4.3. Let G be a graph such that for a pair of vertices u and v there is a unique
shortest path γ between them. Then there is no perfect matching H with an adjacency
matrix B such that B is an automorphism of G without fixed edge and Bu = v.
Proof. Suppose for contradiction that there exists a perfect matching H such that Bu = v.
If γ has an odd number of vertices, then B fixes the central vertex of γ. This is because
there is only one path between u and v, and so Bγ = γ. However, B cannot fix a vertex
of G, since H is a perfect matching. Therefore, γ has an even number of vertices and so
B fixes the central edge of γ, contradicting the assumption that B fixes no edge of G.
Now, we have the following immediately corollary.
Corollary 4.4. For every tree T and every perfect matching H with adjacency matrix B,
if B is an automorphism of T, then B fixes an edge of T.

Degree Sequences
In this subsection, we study the interaction between the degree sequence of a graph and
its primeness. We start with the following lemma.
Lemma 4.6. Let G be a factorable graph. If two vertices a and d are adjacent in G, then
there exist adjacent vertices b and c, such that a, b, c, and d are pairwise distinct and
degG(a) degG(d) = degG(b) degG(c).
Proof. Let G be factored into H and K. Since a and d are adjacent in G, there exist
vertices b and c satisfying the diamond condition (see Figure 4(a)). By Lemma 2.6, we
have:
degG(a) degG(d) = degK(a) degH(a) degK(d) degH(d)
= degK(c) degH(b) degK(b) degH(c)
= degG(c) degG(b).
As a direct consequence of the preceding result, we have the following corollary.
Corollary 4.7. Let G be a connected graph with two adjacent vertices of degrees p and
q, where p and q are prime numbers. If G has neither
(i) a vertex of degree pq, nor
(ii) any vertex of degree 1,
then G is prime.
Proof. Let degG(a) = p and degG(d) = q and G be factored into K and H. By Lemma 4.6
and without loss of generality, we can assume that there are two other vertices b and c such
that degG(b) = p and degG(c) = q. Note a, b, c, and d should satisfy the diamond condition
(see Figure 4(a)). Given that degG(c) = q, so either degH(c) = q or degK(c) = q, see
Lemma 2.6. If degK(c) = q, then degK(a) = q, as c is adjacent to a in H, see Lemma 2.5.

However, this yields a contradiction, as p = degG(a) = degH(a)degK(a) = qdegH(a).
Thus, we have degH(c) = q and so degK(c) = 1. Note d and c are adjacent in K and so

and d are adjacent in K and degK(d) = degK(c) = 1, they form a matched pair.

4.3
Factorization of Grids and Torus
Maghsoudi et al. [5] asked to characterize all factorable grid and torus graphs. We answer
these questions here.
Definition 4.11. (cf. [3, p. 382]) A two-dimensional grid graph, also known as a two-
dimensional lattice graph is an m × n lattice graph that is the Cartesian product Pm□Pn
of path graphs on m and n vertices.
Lemma 4.12. Every grid graph is prime.
Proof. Let G = Pn□Pm. We split our proof depending on the values of m and n.
• If n = 1 and m ≥2, then G ∼= Pm and the result follows from Corollary 4.5.
• If n = m = 2, then G ∼= C4. All vertices have degree 2 and none has degree 2k (k > 1),
so Lemma 4.8 applies.
• Let n ≥2 and m ≥3. Here G contains vertices of degree 3 but none of degree 3k (k > 1);
Lemma 4.8 again yields the result.
Let G be a connected graph. For u, v ∈V (G), let d(u, v) denote their (shortest-path)
distance. For v ∈V (G), its eccentricity is ϵ(v) = maxu∈V (G) d(v, u). The radius of G is
r = minv∈V (G) ϵ(v), and the center is
cen(G) = {v ∈V (G) | ϵ(v) = r}.
Remark 4.13. Every automorphism of G fixes cen(G) setwise.
Next, we have the following folklore result.
Lemma 4.14. Let m, n ∈N.
(i) If exactly one of m or n is even, then the center of Pn□Pm has exactly two adjacent
vertices.
(ii) If both m and n are even, then the center of Pn□Pm has exactly four vertices.
In the next theorem, we discuss when Pn□Pm is factorable. If m = n = 1, then P1□P1
is a single vertex, and its adjacency matrix is a 1 × 1 zero matrix. Trivially, every n × n
zero matrix is the matrix product of two n × n zero matrices.
Theorem 1.4. Let m, n ∈N. Then the Cartesian product Pn□Pm is factorable if and
only if both m and n are even.
Proof. Let G = Pn□Pm.
First, assume G is factorable. By Lemma 4.12, G is prime, and by Remark 3.13 G has
an even number of vertices. Hence at least one of m or n is even.
Suppose for contradiction that exactly one of m, n is even. Then center of G consists
of exactly two adjacent vertices (by Lemma 4.14). By Remark 4.13, every automorphism
10

of G fixes this center edge. However, by Theorem 3.4, B is an automorphism of G with no
fixed edges, contradicting the previous observation. Thus, both m and n must be even.
For the backward implication, assume that both m and n are even. The vertex set of
G is
V (G) = {(i, j) | 1 ≤i ≤n, 1 ≤j ≤m}.
There is a unique shortest path between (1, 1) and (1, m) and similarly between (1, 1) and
(n, 1). Since B is an automorphism of G, it follows that
B(1, 1) = (n, m),
B(n, 1) = (1, m).
Because B does not fix any vertex of G, we deduce that
B(1, i) = (n, m + 1 −i),
B(j, 1) = (n + 1 −j, m).
Applying the same argument,
B(2, i) = (n −1, m + 1 −i),
B(j, 2) = (n + 1 −j, m −1).
By induction, B(i, j) = (n+1−i, m+1−j) defines the unique automorphism, proving
factorability.
Definition 4.15. (cf. [3, p. 382]) The torus or torus grid graph Tm,n is the graph formed
from the Cartesian product Cm□Cn of the cycle graphs Cm and Cn.
Definition 4.16. (cf. [2, p. 34]) If S is a symmetric subset(A set S is symmetric if
S = S−1, where S−1 = { s−1 | s ∈S }.) of a group G, then the corresponding Cayley
graph Cay(G; S) is the undirected graph whose vertices are the elements of G, and such
that vertices x and y are adjacent if and only if x−1y ∈S.

Further research
We close the paper with the following problems:
1. Let d and t be integers with d ≥1 and t ≥3. The windmill graph Wd,t is obtained
by taking d copies of the clique Kt and identifying exactly one vertex from each copy
into a single vertex. We call this shared vertex c and refer to it as the hub. Each
copy contributes t −1 new vertices, so there are d(t −1) non-hub vertices in total.
Furthermore, each non-hub vertex lies in exactly one copy of Kt and is adjacent to
the hub c and to the other t −2 vertices of its own clique. For example, when t = 3,
the graph Wd,3 is exactly the standard friendship graph Fd, and it follows from [5,
Proposition 3.29] that Fd (and hence Wd,3) does not admit a factorization. On the
other hand, the windmill graph W1,4t+1 = K4t+1 does admit a factorization.
We ask to determine all pairs (d, t) for which Wd,t admits a factorization.
